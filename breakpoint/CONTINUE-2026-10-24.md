## 1. Get running (about 5 minutes)

Prereqs: Docker Desktop running, `uv`, Python 3.12, Node 20+.

```sh
cd breakpoint
make setup        # .venv with Python 3.12 and deps
make up           # Postgres 16 in Docker on localhost:5433 (user/pass/db: bp/bp/breakpoint)
make world        # generates data/world/seed42 (gitignored, ~6 s, byte-identical for the same seed)
make test         # expect: 51 passed, 1 skipped (~90 s; tests use their own databases)
make demo         # expect: recall 100%, precision 100%, resolution 33/33, ledger equals truth, invariants green
make api          # builds web/ and serves dashboard + API on http://localhost:8000
```

Optional: `cp .env.example .env` and set `ANTHROPIC_API_KEY` to have the agents decide with Claude (`claude-opus-5-5`).
Without a key, every agent runs its deterministic offline policy. That is how everything has been verified so far.

## 4. Things that will bite you

- **Rules in CLAUDE.md are non-negotiable:** Decimal only (never floats), only the executor writes, never edit a closed
  period, every state change emits an event, the LLM never sets an amount.
- **`make demo` and `make api` share the default database** (`breakpoint`). Running the demo resets what the dashboard shows.
  Tests never touch it.
- **Schema changes:** `reset()` drops and recreates the schema (append-only triggers block deletes), so after changing
  `bp/db.py` just reset; there are no migrations.
- **Break deltas:** position and cash recon subtract the deltas of open breaks *and* the corrections already posted for
  cases still in progress (`Matcher.open_deltas`). Corrections settle with the entry they correct (executor). Change either and
  phantom cash breaks come back. `make demo` catches it (false positives > 0).
- **Expected escalation:** ACC-0052 never answers the cash call (`NO_REPLY` in `outreach.py`, mirrored in `inject.py`), so the second
  ACH return ends in needs_human with the controller. The answer key expects that.
- **API reset button:** it uses `confirm()`. Fine for humans, but it blocks browser automation.
- **Ops lead set to "you (UI)":** in that mode the replay will not teach on its own, so N1 (Aug) and N2 wait in Teach mode until someone teaches them.
  With the scripted ops lead, Dana teaches them automatically the same day.
